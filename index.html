ToolsRTM · Radiative Transfer Suite

ToolsRTM is an R package providing a comprehensive suite of tools for simulating leaf and canopy radiative transfer. It is used within the ESA HYDRA-EO project to generate spectral libraries and trait–reflectance simulations for hyperspectral, fluorescence and thermal Earth Observation.

Overview

The ToolsRTM package provides a unified interface to multiple leaf and canopy radiative transfer models. It supports efficient and accurate simulation of canopy reflectance characteristics and is designed to be combined with SCOPEinR and hybrid machine-learning workflows in HYDRA-EO.

Leaf & canopy

RTMs included

The package covers a range of radiative transfer models for leaf and canopy simulations (e.g. PROSPECT, PROSAIL, FLUSPECT, fourSAIL, INFORM), enabling multi-scale analysis of vegetation optical properties.

Soil & TOA

MARMIT & SPART

ToolsRTM also references soil and soil–plant–atmosphere models (MARMIT, SPART) as described in the README, providing the building blocks for directional TOA reflectance simulations and soil background modelling.

Integration

SCOPEinR & Shiny

The package is designed to work together with SCOPEinR and includes a Shiny-based interface and manuals for interactive exploration of model behaviour.

Installation

The following snippets reproduce the installation examples provided in the ToolsRTM README.

Install ToolsRTM (GitLab / remotes)
▼

## Install ToolsRTM package.
# Only install if not available
if (!requireNamespace("ToolsRTM", quietly = TRUE)) {
  install.packages("remotes")  # just in case remotes isn't there
  remotes::install_gitlab("caminoccg/toolsrtm", upgrade = "never")
}
Install ToolsRTM from .tar.gz
▼

# install ToolsRTM
install.packages('pathWithFile/toolsrtm-main.tar.gz',
                 repos = NULL,
                 type  = "source")
Install additional SCOPEinR package
▼

## Install additional SCOPEinR package using remote. 
remotes::install_gitlab("caminoccg/toolsrtm", upgrade = "never")
# Alternative
install.packages('pathWithFile/scopeinr-main.tar.gz',
                 repos = NULL,
                 type = "source")
