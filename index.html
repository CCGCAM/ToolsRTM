ToolsRTM · Radiative Transfer Package

ToolsRTM provides a unified interface to multiple radiative transfer models (RTMs) for simulating leaf, canopy, soil and top-of-atmosphere optical signals. The package is used within the ESA HYDRA-EO project to generate spectral libraries, trait simulations and forward modelling experiments for hyperspectral, multispectral, fluorescence and thermal Earth Observation.

Overview

ToolsRTM integrates multiple radiative transfer models under one consistent interface. Leaf optical RTMs, canopy reflectance models, soil RTMs and atmosphere–canopy couplings can all be accessed via get.simulator(). The package is designed to support trait retrieval, LUT generation, forward modelling and EO mission analysis within HYDRA-EO.

Leaf & Canopy

Core Radiative Transfer Models

Access to PROSPECT, PROSAIL, FLUSPECT, fourSAIL, fourSAIL2 and INFORM through a unified simulator interface.

Soil & TOA

MARMIT · SPART

Soil moisture/texture simulations (MARMIT) and soil–plant–atmosphere directional TOA reflectance (SPART) support HYDRA-EO multi-sensor modelling.

Integration

SCOPE & Shiny

ToolsRTM interacts with SCOPEinR for fluorescence and energy balance simulations and includes a SHINY interface for model exploration.

Installation

These installation blocks reproduce the exact examples provided in the ToolsRTM README.

Install ToolsRTM from GitLab



## Install ToolsRTM package.
if (!requireNamespace("ToolsRTM", quietly = TRUE)) {
  install.packages("remotes")  
  remotes::install_gitlab("caminoccg/toolsrtm", upgrade = "never")
}

Install ToolsRTM from local tar.gz



install.packages(
  'pathWithFile/toolsrtm-main.tar.gz',
  repos = NULL,
  type  = "source"
)

Install SCOPEinR



## Install additional SCOPEinR package:
remotes::install_gitlab("caminoccg/toolsrtm", upgrade = "never")

# Alternative:
install.packages(
  'pathWithFile/scopeinr-main.tar.gz',
  repos = NULL,
  type = "source"
)

Scientific references

Scientific literature supporting the radiative transfer models included in ToolsRTM.

Leaf optical models

Jacquemoud, S., & Baret, F. (1990). PROSPECT: A model of leaf optical properties. Vilfan et al. (2016, 2018). FLUSPECT-B/Cx for chlorophyll fluorescence modelling.

Canopy models

Verhoef (1984–1998). SAIL family of canopy reflectance models. Atzberger (2000). INFORM canopy model.

Soil radiative transfer

Bablet, Dupiau, Humper, Lesaignoux, Liu, Lobell, Marcq & Philpot soil datasets used for calibration of MARMIT-1 and MARMIT-2 models.

Soil–plant–atmosphere (SPART)

SPART documentation and implementations for coupling soil BRDF, PROSAIL and atmospheric radiative transfer for directional TOA reflectance.

SCOPE (energy balance & fluorescence)

Van der Tol et al. (2009). SCOPE: A coupled energy balance and fluorescence model. Yang et al. (2020). SCOPE-v2 and updates.
