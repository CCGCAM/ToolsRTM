ToolsRTM

Radiative Transfer Modelling Suite used within the ESA HYDRA-EO Project for hyperspectral, thermal and fluorescence simulation, scaling and hybrid ML workflows.

HYDRA-EO · ESA EXPRO+ · Action 1-12684

Overview

ToolsRTM provides a unified interface to multiple leaf-, canopy- and atmosphere-level radiative transfer models (PROSPECT, PROSAIL, FLUSPECT, 4SAIL, INFORM, MARMIT-1/2, SPART). The package enables simulation of reflectance, fluorescence and thermal emission, and supports ESA mission preparatory studies (Sentinel-2, PRISMA, EnMAP, CHIME, FLEX, LSTM). Below are the examples used in the HYDRA-EO web page.

R · ToolsRTM

List available simulators & run PROSAIL

library(ToolsRTM)

ToolsRTM::get.simulator(app='SCOPE')
ToolsRTM::get.simulator(app='getLUT')
ToolsRTM::get.simulator(app='PROSAIL-BRDF')

sim <- ToolsRTM::get.simulator(app="PROSAIL")
out <- sim(Cab = 45, LAI = 3.2)

plot(out$wl, out$R, type = "l",
     xlab = "Wavelength (nm)",
     ylab = "Reflectance")
